# 💰 Expense Tracker

A modern, user-friendly web-based expense tracker application to manage and track your personal expenses efficiently.

## Features

✨ **Easy Expense Management**
- Add new expenses with description, amount, category, and date
- View all expenses in an organized table format
- Delete individual expenses or clear all expenses at once

📊 **Summary Statistics**
- Total expenses tracking
- Current month expenses
- Current week expenses
- Real-time updates of all statistics

🔍 **Filtering & Search**
- Filter expenses by category
- Search functionality for better organization

💾 **Data Persistence**
- All expenses are saved in browser's local storage
- Your data persists even after closing the browser

📱 **Responsive Design**
- Works perfectly on desktop, tablet, and mobile devices
- Beautiful gradient UI with smooth animations

## How to Use

1. **Clone or download the repository**
   ```bash
   git clone https://github.com/kondraakshaya-ops/expense-tracker.git
   cd expense-tracker
   ```

2. **Open the application**
   - Simply open `index.html` in your web browser
   - Or serve using a local server (optional)

3. **Add an Expense**
   - Enter expense description
   - Enter the amount
   - Select a category
   - Choose the date
   - Click "Add Expense"

4. **View & Manage**
   - View all expenses in the table
   - Check summary statistics
   - Filter expenses by category
   - Delete individual expenses or clear all

## Installation & Running

### Option 1: Direct Open
Just open `index.html` in your browser.

### Option 2: Using Python Server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`

### Option 3: Using Node.js
```bash
npx http-server
```
